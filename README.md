## Proyectos destacados

### [Clasificación de defectos en granos de arroz](https://github.com/SantiagoAviles/Rice-Proyect)
Comparación de 5 CNN con transfer learning (ResNet50, EfficientNetB0, DenseNet121, MobileNetV2, InceptionV3) para clasificar defectos en arroz peruano. La mejor fue ResNet50, con 84.7 % de accuracy, y las diferencias entre modelos se validaron con pruebas de McNemar.
Publicado en *AgriEngineering* (2026) · [DOI](https://doi.org/10.3390/agriengineering8060252)
`Python` `TensorFlow` `Jupyter`

### [Vianova](https://github.com/erivero966/vianova-app)
